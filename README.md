# Fasal Saathi App

Build a modern Android mobile application UI named **MeraKeth** for Smart India Hackathon 2026.

Theme:

- Primary Color: Green (#2E7D32)

- Secondary Color: White and Light Green.

- Style: Clean, minimal, farmer-friendly, large buttons and readable fonts.

- Language Support: Hindi + English toggle.

Screen 1 — Welcome Screen

- Logo with a green leaf and crop icon.

- Title: "Fasal Saathi"

- Subtitle: "AI Powered Farm-to-Market Assistant"

- Buttons:

  - Login

  - Register

- Language Selector (English | हिन्दी).

Screen 2 — Farmer Registration

Fields:

- Farmer Name

- Mobile Number

- Email (optional)

- Password

- State

- District

- Village

- Land Size (Acres/Hectares)

- Primary Crop (Dropdown: Wheat, Rice, Soybean, Cotton, Tomato, etc.)

- Preferred Language

- Continue Button

Screen 3 — Crop Budget Setup

Title: "Set Your Crop Budget"

Ask:

"What is your estimated budget for this crop season?"

Input:

- ₹5000

- ₹10000

- ₹15000

- ₹25000

- Custom Amount

Below budget show:

- Seeds

- Fertilizer

- Irrigation

- Pesticide

- Labour

Button:

Save Budget and Continue.

Design should be simple enough for rural farmers with large cards and icons.
